# Plugin Store promo images

Marketing images for the Glue listing on the Craft Plugin Store, rendered in the same theme as the
plugin's marketing page at
[justinholt.com/plugins/craft-glue](https://justinholt.com/plugins/craft-glue).

## Building

```bash
./build.sh          # all slides
./build.sh "2 5"    # just slides 2 and 5
```

Output lands in `out/` as `glue-promo-N.jpg`, 1920×1080 (rendered at 2× in headless Chrome, then
downsampled so the type stays crisp). **Promos are JPEG, never PNG** — Chrome can only write PNG, so
`build.sh` converts with `sips` at quality 90 and deletes the intermediate.

## Palette

Accent `#2E5BBA` from the icon's tile, `#8FB0F0` as the light accent for anything small on the dark
background (cobalt itself is too dark to read as text there), and the family's `#ffd166` gold.
Jersey 20 for display, Inter for body.

## The watermark is the bottle without its tile

`assets/watermark.svg` is the drawing from `../src/icon-mask.svg`, self-coloured white, with no
tile — at watermark scale a rounded square reads as a grey box across the slide. It is anchored
bottom-right, runs off both edges, and is switched off on the cover.

`assets/icon.svg` is a straight copy of `../src/icon.svg`. Re-copy it whenever the icon changes.

## Screenshots

`shots/` holds four crops of real captures from the plugin-testing harness, on demo content:

1. `fixture.php` builds a News section with two write-ups of the same library reopening, three
   events linking to one of them, same-titled pairs for the duplicate finder, and three more pairs.
   Handles all start `release`/`promo`; `--clean` removes the lot.
2. `history.sh` merges those three pairs over HTTP as the admin, so the history has rows with a user.
3. `capture.mjs` logs in, clicks “Both” on Topics and Content blocks, opens the actions menu with the
   pair selected, and screenshots each screen at 1500 CSS px, 2×.

```sh
cd ~/Sites/plugin-testing
ddev exec php /var/www/craft-glue/tests/integration/edition.php pro
JSON=$(ddev exec php /var/www/craft-glue/promos/fixture.php)
ddev exec bash /var/www/craft-glue/promos/history.sh "$JSON"
node ~/Sites/craft-glue/promos/capture.mjs <outDir> <a> <b> <sectionId>   # ids from $JSON
```

The harness serves on `https://plugin-testing.ddev.site:33019`, not the bare hostname. `capture.mjs`
borrows puppeteer from `~/Sites/plugin-shots/node_modules`.

The harness is shared with every other plugin, so `capture.mjs` hides what is not Glue's in the DOM
rather than touching data: other plugins' nav items, toolbars and section sources; the Authors and
History “By” columns (the admin has been renamed by another plugin's tests); history rows from the
integration tests; and the duplicate group created by the history fixture's own new-entry merge.

Don't run `cp-smoke.sh` at the same time — it flips the edition to Lite and back.

`capture.mjs` screenshots the merge screen's Fields panel and the `#content` pane of Duplicates and
History as elements, so those three need no cropping and survive layout changes. The index shot is a
viewport capture, cropped to the sources and table (2× pixels; an offset of `0 0` is ignored):

```sh
sips --cropToHeightWidth 1860 2490 --cropOffset 95 460 glue-index.png --out shots/glue-index.png
```

The harness is often busy with other plugins' queue jobs, so the index can take a while to load —
`capture.mjs` waits up to two minutes for the rows.

`fonts.css` is generated by `build.sh` and gitignored; don't edit it.
